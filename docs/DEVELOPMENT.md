# 开发与验证记录

## 选题与设计

维护者 hxiuzheng 确定字幕质量与无障碍检查方向，面向课程、短视频及培训内容的发布前复核。项目采用 MoonBit，诊断结果需要能定位到字幕源文件，中文阅读规则需可调整。

AI 辅助完成接口、实现、测试和文档草稿。默认阈值及报告表达仍需维护者结合实际素材审阅。自动测试通过不表示维护者已逐行审查或完成真实用户试用。

## 2026-11-03：本地草稿验证

首轮 10 个自动测试中 9 个通过，发现 CRLF 规范化仅替换首处。修正为全量替换，同时修正 HTML 转义的全量处理。保留 BOM/CRLF 和重复 HTML 标签测试。

区间复核发现，乱序但不相交的字幕不应报为重叠。实现改为按开始时间扫描有效区间；源文件乱序独立报告。测试补充长区间包含短区间、相邻区间、空字幕和阅读速度边界。

## 2026-11-07：第一批公开范围

将既有本地草稿按组件分批公开。本批包含校验库、报告 API、14 个核心测试及基础说明；后续批次补充命令行、使用示例与工程文档。批次代表公开范围，不代表重新开发或额外人工测试。

本批验证命令：

```sh
moon check --deny-warn
moon test --deny-warn
moon build --deny-warn
moon fmt --check
moon run tools/identity.mbtx
```

## 2026-11-08：第二批公开范围

公开本地草稿中的命令行、SRT 和 WebVTT 示例，以及文本、JSON 和 HTML 报告的使用方式。命令行复用首批校验接口。默认允许警告，`--strict` 将警告计入退出码。

复跑检查、构建和格式校验，14 个核心测试和 8 个命令行场景全部通过。WebVTT 示例的 JSON 报告记录了显示过短、阅读过快和字幕重叠三项警告，写入文件的 HTML 报告包含对应诊断链接和字幕锚点。
