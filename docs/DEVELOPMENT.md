# 开发与验证记录

## 选题与设计

维护者 hxiuzheng 确定字幕质量与无障碍检查方向，面向课程、短视频及培训内容的发布前复核。项目采用 MoonBit，诊断结果需要能定位到字幕源文件，中文阅读规则需可调整。

AI 辅助完成接口、实现、测试和文档草稿。默认阈值及报告表达仍需维护者结合实际素材审阅。自动测试通过不表示维护者已逐行审查或完成真实用户试用。

## 2026-11-03：本地草稿验证

首轮 10 个自动测试中 9 个通过，发现 CRLF 规范化仅替换首处。修正为全量替换，同时修正 HTML 转义的全量处理。保留 BOM/CRLF 和重复 HTML 标签测试。

区间复核发现，乱序但不相交的字幕不应报为重叠。实现改为按开始时间扫描有效区间；源文件乱序独立报告。测试补充长区间包含短区间、相邻区间、空字幕和阅读速度边界。

## 参赛预审补强

以公开提交 `89cb5cc` 为基线，维护者提出对照参赛要求检查仓库。AI 辅助复现边界问题、实现补强并运行回归。以下按可单独审阅的改动记录。

1. 解析与恢复。WebVTT 接受可表示的长时码和制表符分隔设置，检查毫秒上界，发现缺失的头部空行和重复时间箭头后保留可解析的字幕。未闭合的尖括号保留在阅读速度计数中。
2. 报告与文件保护。HTML 按播放时间排序，语法错误显示源行号，完整字幕的诊断保留可点击链接。CLI 独占创建报告，验证脚本检查源字幕和已有报告的内容在重试后保持一致。
3. 修订回归。按显式、唯一的 WebVTT cue ID 匹配版本，区分增删、改字和超过容差的时轴移动。无效输入按两版分别诊断，避免给出误导的对比结果。文本、JSON 与并排 HTML 可分别用于发布流程和人工审阅。
4. 复现与申报。对照章程补齐 [申报事实与场景核对](PROPOSAL.md)、[验收复现步骤](ACCEPTANCE.md) 和依赖来源。MoonBit v0.10.20 本地通过 27 个核心测试、13 个命令行退出码场景、报告文件验证和修订 HTML 验证，模块可打包。
